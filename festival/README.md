## 何ができるアプリか（3行）
　　頭、体、手、足、羽、尻尾などの体のパーツを組み合わせて自分だけのオリジナルモンスターを作る。
   パーツの組み合わせによっては攻撃や防御、素早などが上がったり下がったりする。
   その作ったモンスターのステータスやランクをつける。D C B A S SS 
   (ステータスやランクは勝手につけてくれる。)
   モンスターが使う技を選択する。
   パーツによって使える技が広がる。（例：ドラゴンの頭→「炎の息吹」)
   逆に組み合わせで使えなくなる技もある。
   相手が作ったモンスターと対戦する。
