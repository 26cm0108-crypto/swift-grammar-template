## 何ができるアプリか（3行）
　　・頭・体・手・足・羽・尻尾などのパーツを自由に組み合わせて、自分だけのオリジナルモンスターを作れる。
・パーツの組み合わせによってステータスやランクが決まり、使える技も変化する。
・完成したモンスターの技を選び、ほかの人が作ったモンスターと対戦できる。
